## Current-date tokenizer incompatibility

The pinned `TokenizedDataset._prefix_pattern` accepts Llama template `Today Date` years `2024` and `2025` only. On 30 September 2026, the pinned Llama tokenizer renders `Today Date: 30 Sep 2026`, and the unmodified upstream mask parser asserts on the first real fact. The prior local wrapper bypassed this parser, so its success does not establish source parity. A source-era date injected only into a structural diagnostic showed identical prompt IDs and nonempty fact mask positions, including an upstream-retained empty fact mask, plus identical roleplay/control generation IDs. The v3 adapter extends the mask parser to 2026 without changing rendered prompt text; the direct pinned-source tests pass. No v3 model collection has used the diagnostic date.
