# Verified Reasoning Monitoring

Can internal activation signals help a frozen language model find more externally
verified solutions under the same total inference-time budget?

**Status: implementation and feasibility assessment. No empirical result yet.**
The first study ranks short, complete Lean proof proposals. Ranking existing
candidates is not evidence of improved underlying reasoning ability.

This is a separate follow-up to
[Familiarity x Answerability](https://github.com/Fredo220/Answerability-x-Familarity-).
That study's outcomes, datasets, thresholds, and trained probes are not reused.

See [the research protocol](docs/research_plan.md) and
[implementation status](docs/status.md). No paid services are required or invoked.
